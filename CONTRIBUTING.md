# Contributing to Curated AI Agents

Thank you for your interest in contributing to this curated list! Your help in keeping this resource comprehensive and up-to-date is greatly appreciated.

## How to Contribute

### Adding a New AI Agent or Tool

1. **Fork** this repository
2. **Add your entry** to the appropriate section in `README.md`
3. **Submit a pull request** with a clear description

### Entry Format

Each entry should follow this format:

```markdown
- **[Name](url)** - A concise one-sentence description of what the tool does.
```

### Requirements for New Entries

Before submitting, please ensure the tool meets these criteria:

- [ ] The project is actively maintained (commits within the last 6 months)
- [ ] The project has clear documentation or a README
- [ ] The link is valid and points to the official source
- [ ] The description is concise (one sentence) and accurately describes the tool
- [ ] The entry is placed in the correct category
- [ ] The entry is added in alphabetical order within its category
- [ ] For open-source tools, link to the GitHub/GitLab repository
- [ ] For commercial tools, link to the official website

### What Qualifies as an AI Agent?

For this list, an AI agent is defined as software that:

- Uses large language models (LLMs) or AI for decision-making
- Can autonomously perform tasks with minimal human intervention
- Interacts with external tools, APIs, or environments
- Goes beyond simple prompt-response chatbot interactions

### Categories

- **Agent Frameworks** - General-purpose frameworks for building AI agents
- **Multi-Agent Platforms** - Platforms for orchestrating multiple cooperating agents
- **Code Agents** - Agents specialized in software development and coding
- **Research Agents** - Agents focused on information gathering and research
- **Browser Agents** - Agents that can navigate and interact with web browsers
- **Task Automation** - AI-powered workflow and business process automation
- **Agent SDKs & Libraries** - Development kits and libraries for building agents
- **Agent Monitoring & Evaluation** - Tools for monitoring and evaluating agent performance

If your tool doesn't fit an existing category, feel free to suggest a new one in your pull request.

## Updating an Existing Entry

If you notice outdated information, broken links, or inaccurate descriptions:

1. Open an issue describing the problem, or
2. Submit a pull request with the correction

## Reporting Issues

- **Broken links**: Open an issue with the title "Broken link: [tool name]"
- **Inaccurate descriptions**: Open an issue explaining what's wrong
- **Duplicate entries**: Open an issue identifying the duplicates

## Code of Conduct

- Be respectful and constructive in all interactions
- Focus on the quality and relevance of contributions
- No spam or self-promotion without genuine value to the community
- Maintain objectivity in descriptions (no marketing language)

## Review Process

All submissions are reviewed by maintainers. We aim to review pull requests within a week. A submission may be rejected if:

- The tool doesn't meet the quality criteria above
- The description is promotional rather than informative
- The project is abandoned or unmaintained
- The tool is a minor fork without significant differentiation

## Questions?

If you have questions about contributing, feel free to open an issue with the "question" label.

Thank you for helping make this list a valuable resource for the AI agent community!
